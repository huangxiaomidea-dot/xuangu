# 东南亚中国企业主要建设项目清单 及 美的集团可提供的服务方案

> 调研日期：2026年7月
> 说明：东南亚在建/近期建设的中资项目数以千计，无法穷尽罗列。本文按国别梳理**主要及代表性项目**（以基建、产业园、能源、制造业工厂、数据中心为主），并结合美的集团（Midea Group）的 ToB 业务能力，给出可切入的服务方案。

---

## 二、美的集团可提供的服务

美的已从家电公司转型为"智能家居 + 楼宇科技 + 工业技术 + 机器人与自动化 + 数字化创新"的科技集团，且在东南亚有深厚本地布局（泰国罗勇智能制造产业园2025年动工，越南、马来西亚、印尼均有生产基地），可为上述项目提供以下服务：

### 1. 楼宇科技（美的楼宇科技 MBT）——最直接的切入点
- **中央空调/暖通（HVAC）**：多联机、大型离心/螺杆冷水机组、单元机，适配高铁站房、机场航站楼、产业园厂房、商业综合体、医院学校等。参考案例：新加坡樟宜机场、巴西世界杯场馆等超10万个大型工程。
- **区域供冷/集中制冷**：已中标新加坡最大政府组屋集中制冷项目，可复制到马来西亚柔佛、印尼新首都努山塔拉、泰国EEC等新城开发。
- **数据中心温控**：机房精密空调、磁悬浮冷机、间接蒸发冷却、液冷方案——正对接马来西亚柔佛、泰国、印尼的中资数据中心建设潮。
- **电梯（LINVOL 凌越等品牌）**：直梯、扶梯、货梯，适配轨交车站、机场、产业园宿舍与商业楼宇。
- **iBUILDING 数字化平台 + 楼宇自控（BA）**：提供从顶层设计、机电实施到后期运维、能碳管理的全栈智慧建筑解决方案，适合工业园区综合能源管理和绿色建筑认证需求。

### 2. 机器人与工业自动化（库卡 KUKA）
- 为比亚迪、长安、吉利、宁德时代等在泰国、印尼、马来西亚的整车厂/电池厂提供**工业机器人、焊装/涂装/总装自动化产线、AGV/AMR 物流机器人**及产线集成服务。
- 为电子制造（越南立讯、歌尔等供应链）提供小型机器人与柔性装配方案。

### 3. 新能源与储能（美的工业技术：科陆电子、合康新能等）
- **储能系统（ESS）**：为老挝、柬埔寨、菲律宾的光伏电站提供储能变流器、集装箱式储能与微网方案。
- **光伏逆变器、充电桩、热泵**：配套园区分布式光伏、新能源车厂充电设施；热泵产品可服务出口型工厂的绿色工艺用热。
- **电能质量与配电设备**：产业园区变配电、无功补偿方案。

### 4. 智能家居与家电大宗配套
- 面向房地产、酒店、公寓、TOD 站城开发（如中老铁路沿线、森林城市类项目）提供**全屋家电+智能家居系统**的工程大宗采购与本地化售后。

### 5. 供应链物流与数字化服务
- **安得智联**：为中资工厂提供东南亚仓配一体、跨境物流与产线内物流方案。
- **美云智数（Midea Cloud）**：向出海中企输出灯塔工厂经验——MES、WMS、数字孪生、能碳管理等工业软件与咨询实施。

### 6. 本地化优势
- 泰国（罗勇产业园）、越南、马来西亚、印尼、埃及等地有自有工厂，可实现**本地供货、本地工程服务、本地售后**，缩短交期并满足东道国本地化率要求；同时熟悉中资总包（中交、中铁、电建、能建等）的采购体系，易于以分包/设备供应商身份进入项目。

### 7. 项目—服务匹配速查

| 项目类型 | 美的可提供的核心服务 |
|---|---|
| 铁路/轨交（雅万、中泰、ECRL、越南铁路） | 站房中央空调、电梯扶梯、楼宇自控、站城综合体家电配套 |
| 数据中心（马来西亚、泰国、印尼） | 精密温控、磁悬浮/液冷、配电与能管平台 iBUILDING |
| 汽车/电池工厂（比亚迪、宁德、吉利、长安） | KUKA 机器人产线、工业空调、储能+光伏、安得物流 |
| 产业园区（青山、罗勇、赛色塔、西港特区） | 园区综合能源、区域供冷、厂房暖通、宿舍家电、数字化园区 |
| 光伏/水电/电网（老挝、柬、菲） | 储能系统、逆变器、电能质量设备 |
| 机场/港口/运河 | 大型冷水机组、电梯、智慧楼宇、后勤家电 |
| 地产/新城（努山塔拉新首都、TOD 开发） | 全屋智能+家电大宗、集中制冷、电梯 |
